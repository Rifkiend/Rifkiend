## 🤝 Featured — [TheRoster](https://github.com/Rifkiend/TheRoster) · v2.6.0

An **Agent Skill** that gives every AI the same team. Before any job, the AI loads a written roster — if someone isn't on the list, they're not a teammate, don't invent them. Disconnected AIs claim work without colliding, reuse features instead of rebuilding them, and continue each other's work in place. Now at **v2.6.0** — fan-out, decision gates, typed receipts, and formal reviews, still with no server.

```bash
npx skills add Rifkiend/TheRoster
```

> One team. Every AI. Zero guesswork.
